# 声绘魔法（VoiceCanvas）

声绘魔法是一款供个人使用的 macOS 桌面应用，通过 MiniMax API 提供语音合成、音色克隆、音色设计和用量报表。它将配置、文本标注、分段试听、整篇导出和音色管理集中在本地界面中，适合在自己的 Mac 上完成日常配音工作。

## 核心功能

- **工作台**：编辑原文，使用 AI 润色标注，并继续调整 `[emotion]` 情绪标签与 `(语气词)`；支持分段试听、失败段标记与单段重试试听、整篇合成导出、音效器和草稿自动保存。
- **音色库**：浏览系统音色；上传音频克隆音色，可填写克隆提示词（参考文本）；根据文字描述设计音色；管理本地音色备注。
- **用量报表**：查看按天或按周的趋势、按功能拆分的统计和调用明细；支持按时间范围及功能筛选、分页、CSV 导出，并可根据配置的单价估算费用。
- **音频格式**：支持 MP3、WAV 和 FLAC。

## 系统要求

- macOS
- Python 3.13 或更高版本
- 有效的 MiniMax API 凭据

应用通过 `imageio-ffmpeg` 内置 ffmpeg，正常安装 Python 依赖后无需另外安装系统级 ffmpeg。

## 安装与启动

在项目目录中依次运行：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 -m app.main
```

启动后会打开原生应用窗口；本地服务会在后台使用随机端口运行。

## 首次配置

首次使用前，在配置页完成以下设置：

1. 输入 API Key，然后点击 API Key 旁独立的“保存”按钮。应用会将 Key 保存到 macOS Keychain，界面只显示掩码。
2. 设置模型、输出格式、采样率、MP3 比特率、音频保存目录和 API Base URL。Group ID 为可选项，仅在账户或接口要求时填写；如需费用估算，也可填写费用单价。确认后点击“保存设置”。默认音频保存目录为 `~/Music/VoiceCanvas`。
3. 点击“测试连接”，确认已保存的凭据、服务地址和网络连接可用，再进入工作台。测试连接读取的是已保存配置，因此必须先完成前两步的保存操作。

## 基本使用流程

1. 在工作台输入或粘贴原文，根据需要运行 AI 润色标注，然后检查并编辑生成的 `[emotion]` 与 `(语气词)` 标记。编辑内容会自动保存为草稿。
2. 合成前选择音色，并设置语速、音量、Pitch 和可选的音效器。
3. 点击“解析分段”，再逐段试听；不满意时继续修改文本、标记或合成参数。
4. 点击“整篇合成并导出”生成成品。
5. 如果部分段落合成失败，首次导出的文件只包含成功段。点击失败段的“重试”只会重新合成并播放该段，不会自动把重试结果补入已经导出的文件。若要获得包含全部段落的成品，请再次点击“整篇合成并导出”；此时所有段落都会重新生成。

音色克隆和音色设计可在音色库中完成；生成或保存的音色可供工作台选择。用量报表会记录调用情况，便于查看趋势、明细与费用估算。

## 音频输出说明

- MP3 支持 32、64、128、256 kbps，均使用恒定比特率（CBR）。
- WAV 和 FLAC 不应用 MP3 比特率设置。
- 每两个成功合成的相邻段之间固定插入 1 秒静音；音频开头和结尾不会额外添加静音。
- 一次生成开始时会锁定输出格式、采样率和比特率。该次生成中的分段合成、失败段重试和最终拼接都会复用这组设置，避免同一成品内参数不一致。

## 数据与隐私

- 应用数据默认保存在 `~/Library/Application Support/VoiceCanvas/`，其中包括配置文件和 SQLite 数据库。
- API Key 保存在 macOS Keychain，不以明文写入应用数据目录。
- 音频默认输出到 `~/Music/VoiceCanvas`，可在配置页更改。
- 首次启动新版时，应用会尝试迁移旧 VoiceMax 数据和凭据；迁移失败时会安全回退，避免用不完整的迁移结果覆盖可用数据。

本地存储不等于离线处理。语音合成、音色克隆、音色设计及其他需要 MiniMax API 的功能，会把完成请求所需的数据发送到你在配置页指定的 API Base URL。请在提交文本或音频前确认该服务地址及其隐私政策符合你的要求。

## 测试

在已激活的虚拟环境中运行：

```bash
pytest -v
```

测试使用 `respx` 拦截 MiniMax 请求，不消耗真实额度。GitHub Actions 会在每次推送到 `main` 以及合并请求中使用 macOS 和 Python 3.13 运行完整测试。

## macOS 打包

打包脚本会先安装或更新构建依赖并运行完整测试，再生成指定架构的应用：

```bash
scripts/build_app.sh arm64
scripts/build_app.sh x86_64
```

构建产物位于 `dist/<arch>/声绘魔法.app`。构建 x86_64 版本需要 Rosetta 2。只有当前 Python 解释器及全部依赖都提供 universal2 支持时才能使用 `universal2`；否则应分别构建 arm64 和 x86_64 版本。构建目录和发行产物均为本地生成内容，不纳入 Git。

## 项目结构

- `app/`：FastAPI 路由、业务服务和 SQLite 数据层。
- `web/`：原生 HTML、CSS 和 JavaScript 前端资源。
- `tests/`：pytest 测试。
- `scripts/`：应用图标生成及 macOS 打包脚本。
- `docs/`：设计与维护文档。
